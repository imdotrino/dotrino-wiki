# QRShare — moving files between devices

[`qrshare.dotrino.com`](https://qrshare.dotrino.com/) · repo
[`dotrino-qrshare`](https://github.com/imdotrino/dotrino-qrshare)

Getting a photo from your phone to your computer usually ends in emailing yourself
or uploading the file to someone else's cloud. QRShare takes the short path: the
file travels **straight from one device to the other**.

## How to use it

1. Open the app on the device that **has** the file and pick it.
2. A **QR code** appears. Scan it with the other device (or open the link).
3. The two devices connect and the file goes across.

Both have to have the app open at the same time: it is a hand delivery, not a
mailbox.

## What never goes through a server

The contents of the file. The server is used only so the two devices can find each
other; the bytes go direct. That is why there is no size limit set by an account
and no file of yours sitting on anyone's disk.
