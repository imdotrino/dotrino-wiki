# Reading and creating QR codes

Two small utilities with the same rule: **all the work happens inside your
browser**. Neither the image nor the text leaves your device.

## QR Reader — reading

[`qrreader.dotrino.com`](https://qrreader.dotrino.com/) · repo
[`dotrino-qrreader`](https://github.com/imdotrino/dotrino-qrreader)

1. Open the app and point the camera, or **upload an image** you already have.
2. What the code contains is shown.
3. If it is a link, one button opens it; if it is text, you can copy it.

Handy when the code is inside a screenshot or a PDF and there is nothing to point
the camera at.

## QR Generator — creating

[`qrgenerator.dotrino.com`](https://qrgenerator.dotrino.com/) · repo
[`dotrino-qrgenerator`](https://github.com/imdotrino/dotrino-qrgenerator)

Create a QR from:

| Type | What it is for |
|---|---|
| Link or text | the common case: a web address, a note |
| Wi-Fi network | let a guest connect without reading out the password |
| Contact | hand over your card without typing anything |
| Location | a point on the map |

Download it as **PNG** (to paste anywhere) or **SVG** (to print it large without
going blurry).
