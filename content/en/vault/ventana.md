# The vault window

**Dotrino Vault** is your vault's control screen, with buttons instead of keys. It has
exactly the same as the [terminal UI](/en/vault/tui/): they are the same screen drawn two
ways, so whatever one can do the other can too.

It comes with the [Linux](/en/vault/instalar-linux/), [Windows](/en/vault/instalar-windows/)
and [macOS](/en/vault/instalar-macos/) installers. On Linux it is in the applications menu,
or `dotrino-vault-desktop`.

## How to use it

- **Vaults.** The list of your profiles. Click one, then **Open** (or double-click).
- **Inside a vault**, four tabs: **Devices**, **Scopes & variables**, **Sign in** (user
  and password) and **Profile**. **← Vaults** goes back to the list.
- **The buttons at the bottom** are what can be done there, with their key next to them.
  The keys work too: `p` pairs, `n` creates, `F5` refreshes.
- **Pair** shows the QR code to scan with the other device, with **Copy link** and **Copy
  code** when there is no camera.
- **Questions and confirmations** show up in a box on top. Passwords are hidden as you
  type them.
- **ES / EN**, top right, switches the language.

## If the vault is not running

The window says so and offers **Start**. The vault keeps running with no window; closing
the window does not stop it.

## When you close the window

The vaults you opened with their password in this window are locked again.
